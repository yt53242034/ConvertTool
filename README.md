# 圖片轉 SVG/DXF 轉換工具 (Image to Vector Converter)

這是一個基於 Python Tkinter 開發的圖形介面工具，專門將點陣圖（JPG, PNG, BMP 等）轉換為向量格式（SVG 或 DXF）。

本工具特別整合了 **中心線提取 (Centerline)** 與 **輪廓追蹤 (Outline)** 兩種模式，並支援 **局部閾值調整 (ROI)** 與 **DXF 輸出**，非常適合雷射切割、CNC 加工或向量繪圖需求。

## ✨ 功能特色

- **雙重轉換模式**：
  - **提取中心單線 (Centerline)**：
    - 使用 Python `scikit-image` 骨架化演算法。
    - 將線條縮減為單一路徑，適合工程圖或路徑加工。
    - 內建雜點過濾與毛邊修剪 (Pruning) 機制。
  - **輪廓追蹤 (Outline)**：
    - 整合 `Potrace` 引擎。
    - 描繪圖形的邊緣輪廓，適合一般向量設計或圖標製作。
- **局部閾值調整 (ROI)**：
  - 可在圖片上框選多個特定區域，個別設定不同的二值化閾值。
  - 解決全域閾值無法同時處理「去除雜點」與「保留淡色線條」的兩難。
- **多格式輸出**：
  - **SVG**：標準向量圖格式。
  - **DXF**：AutoCAD R2010 格式（使用 `ezdxf` 生成），分層管理（CENTER 層），單位為毫米 (mm)。
- **即時預覽**：提供原始圖片與二值化後的預覽對照，支援滑鼠滾輪縮放與拖曳平移。
- **自動化環境建置**：
  - 自動檢查並安裝所需的 Python 套件 (`Pillow`, `scikit-image`, `numpy`, `rdp`, `ezdxf`)。
  - 自動下載並配置 `potrace.exe`（Windows 系統若未安裝會自動處理）。

## 🛠️ 系統需求

- **作業系統**：Windows 10/11 (64-bit) 推薦
  - *註：程式碼內建的 Potrace 自動下載功能主要針對 Windows。Linux/Mac 使用者需自行安裝 Potrace (例如 `sudo apt install potrace` 或 `brew install potrace`)。*
- **Python 版本**：Python 3.8 或更高版本。

## 🚀 安裝與執行

### 方法一：直接執行 (推薦)

本程式內建自動安裝機制。您只需確保電腦已安裝 Python，直接執行程式碼即可：

```bash
python ConvertTool.py
```

首次執行時，若缺少必要套件或 `potrace.exe`，程式會彈出視窗詢問並自動嘗試下載安裝。

### 方法二：手動安裝依賴

若您希望手動管理環境，請先安裝以下套件：

```bash
pip install Pillow scikit-image numpy rdp ezdxf
```

若您需要使用「輪廓模式」，請下載 Potrace 並將 `potrace.exe` 放置於程式同一目錄下的 `potrace/` 資料夾中，或確保其位於系統 PATH 中。

## 📖 使用說明

1. **開啟程式**：執行 `ConvertTool.py`。
2. **載入圖片**：點擊左上角的「開啟圖片」按鈕，選擇您的圖檔。
3. **調整預覽**：
   - 使用滑鼠滾輪可縮放圖片。
   - 按住滑鼠左鍵可拖曳圖片。
   - 右側視窗顯示的是「二值化」後的預覽結果。
4. **全域設定**：
   - 調整「全域閾值」滑桿，設定整張圖片的基礎黑白分界。
5. **局部區域調整 (進階)**：
   - 若圖片某些區域雜點過多或線條太淡，點擊 **「新增局部調整區域」**。
   - 在左側原圖上拖曳滑鼠框選區域。
   - 調整 **「局部閾值」** 滑桿，該區域的預覽會即時更新。
   - **選取與修改**：點擊已存在的紅框（變為藍框），可重新調整該區域數值或點擊「刪除選取區域」。
6. **選擇模式**：
   - **勾選**「提取中心單線」：輸出單線條骨架（適合 CNC/雷切）。
   - **不勾選**：輸出邊緣輪廓（適合平面設計）。
7. **開始轉換**：
   - 點擊下方的「開始轉換 SVG」按鈕。
   - 在存檔對話框中，您可以選擇存檔類型為 **SVG** (`.svg`) 或 **DXF** (`.dxf`)。
   - 等待進度條跑完，轉換完成後會跳出提示。

## ⚙️ 技術細節

- **影像前處理**：圖片會先經過對比度增強與銳化。
- **混合二值化**：程式支援「全域閾值」與多個「局部閾值」遮罩的混合運算，確保細節保留。
- **中心線演算法**：
  - **骨架化**：使用 `scikit-image` 的 `skeletonize`。
  - **修剪 (Pruning)**：基於節點分析，去除短於特定長度的毛邊與雜線。
  - **向量化**：使用圖論搜尋演算法追蹤像素路徑，並處理交叉點與封閉迴圈。
  - **簡化**：使用 RDP (Ramer-Douglas-Peucker) 演算法減少向量節點數量。
- **DXF 輸出**：使用 `ezdxf` 庫生成 R2010 格式 DXF，線條置於 `CENTER` 圖層 (紅色)。

# 圖片 轉 SVG 轉換工具 (Image to SVG Converter)

這是一個簡單且實用的 Python 工具，提供圖形化介面 (GUI)，協助使用者將 JPG/JPEG/PNG 等點陣圖片轉換為 SVG 向量圖檔。核心轉換引擎採用業界標準的 `Potrace`，專精於高品質的黑白/單色向量化描摹。

## 功能特色

- **圖形化介面 (GUI)**：使用 Tkinter 構建，操作簡單直觀，無需輸入複雜指令。
- **自動依賴檢查**：啟動時會自動檢查 `Potrace` 與 `Pillow` 是否已安裝。
- **彈性輸出設定**：使用者可選擇轉換後的檔案儲存位置。
- **Potrace 整合**：呼叫高效能的 Potrace 演算法，產生平滑的向量線條。
- **狀態提示**：轉換成功或發生錯誤時，皆會彈出視窗提示。

## 安裝需求

在使用此工具之前，請確保您的電腦已安裝 Python 3.x。

### 安裝依賴套件

本專案依賴 **Potrace** 命令列工具與 **Pillow** Python 套件。

1. **Potrace**: 程式會嘗試自動下載。若需手動下載，請前往 SourceForge 下載 **`potrace-1.16.win64.zip`** 並將 `potrace.exe` 放入程式目錄下的 `potrace` 資料夾中。(⚠️注意：請勿下載 `.tar.gz` 檔，那是原始碼)。
2. **Pillow**: 用於圖片處理。程式啟動時會自動檢查並詢問安裝，或手動執行：
   ```bash
   pip install Pillow
   ```

*備註：`tkinter` 為 Python 標準庫的一部分，通常無需額外安裝。*

## 如何使用

1. 下載專案程式碼 `ConvertTool.py`。
2. 確保 `potrace.exe` 已放置於 `potrace` 資料夾中（或讓程式自動下載）。
3. 在終端機中執行程式：

   ```bash
   python ConvertTool.py
   ```

4. 程式視窗開啟後，點擊 **「選擇圖片並轉換」** 按鈕。
5. 在檔案瀏覽器中選擇您想要轉換的圖片檔案（如 `.jpg`, `.png` 等）。
6. 接著選擇**輸出資料夾**。
7. 等待轉換完成。成功後會彈出視窗提示，您可以在指定的資料夾中找到生成的 `.svg` 檔案。

## 進階設定

若您需要調整轉換效果，可以直接在介面上調整參數：

- **雜點過濾 (Turdsize)**: 忽略小於指定像素面積的雜點。
- **黑白閾值 (Threshold)**: 決定圖片轉為黑白的明暗分界點 (0.0 - 1.0)。

# ConvertTool - 圖片轉 SVG / DXF 向量工具

使用 Python + Tkinter 製作的桌面工具，將圖片（JPG / PNG / BMP / WEBP）轉換成 `SVG` 或 `DXF`。

此工具針對「線稿處理」與「CAD / CNC / 雷射加工前整理」做了額外強化，支援：

- 外框向量化（Potrace）
- 中心線向量化（Python 內建骨架化流程）
- ROI 區域局部閾值（不同區域用不同二值化門檻）
- 即時預覽（二值化 / 中心線效果）
- 去除粗邊 / 智慧修邊 / 平滑化（含強度滑桿）

## 功能重點

### 1. 兩種向量化模式

- 外框模式（Outline）
  - 使用 `Potrace` 將黑白圖追蹤成向量外框
  - 適合 Logo、實心圖形、邊界輪廓
- 中心線模式（Centerline）
  - 使用 `scikit-image` 骨架化（skeletonize）
  - 自動抽取線段路徑並輸出 SVG / DXF
  - 適合筆畫線稿、雕刻路徑、中心線需求

### 2. ROI 區域閾值（局部二值化）

可在原圖上框選區域（ROI），針對局部指定不同閾值，解決同一張圖亮度不均、局部太淡或太黑的問題。

### 3. 影像前處理與清理（可調強度）

可選用以下功能來修正線條品質，並透過強度滑桿（`0~4`）微調效果：

- 線條細化（去除粗邊）
- 去除沾黏（智慧修邊）
- 連接鄰近線條（平滑化）

說明：

- `0` 代表關閉該強度（即使勾選功能，也可用 0 做快速比對）
- 預覽與最終輸出使用相同參數，避免預覽好看但匯出結果不同

### 4. 輸出格式

- `SVG`
  - 路徑輸出為平滑曲線（含簡化）
- `DXF`（AutoCAD R2010）
  - 使用 `ezdxf`
  - 建立 `CENTER` 圖層
  - 單位設為 `mm`

## 系統需求

- Windows 10 / 11（主要開發與測試環境）
- Python 3.8+

其他平台（Linux / macOS）理論上可用，但需要自行安裝 Potrace 並確認路徑。

## 安裝方式

### 1. 安裝 Python 套件

```bash
pip install -r requirements.txt
```

`requirements.txt` 內容：

- Pillow
- scikit-image
- numpy
- rdp
- ezdxf

### 2. Potrace（必要）

本工具外框向量化需要 `potrace`。

程式啟動時會自動檢查：

- 系統 `PATH` 中的 `potrace`
- 專案內 `potrace/potrace.exe`

若找不到，程式會提示是否自動下載 Windows 版 Potrace。

## 啟動方式

### 方式 A：直接執行 Python

```bash
python ConvertTool.py
```

### 方式 B：使用批次檔（Windows）

```bash
RunConvertTool.bat
```

## 使用流程（快速上手）

1. 點擊「開啟圖片」載入檔案
2. 觀察右側預覽（即時二值化/中心線預覽）
3. 調整參數
   - 全域閾值
   - 雜點移除（px）
   - 是否啟用中心線模式
   - 去除粗邊 / 智慧修邊 / 平滑化
   - 各功能強度（0~4）
4. 必要時使用 ROI 模式框選區域，設定區域閾值
5. 點擊轉換，選擇輸出格式（SVG 或 DXF）
6. 等待完成，程式會提示成功並開啟輸出資料夾

## 參數說明（建議）

### 全域閾值

- 範圍：`0.0 ~ 1.0`
- 效果：決定黑白二值化門檻
- 建議起點：`0.65`

### 雜點移除（px）

- 用於移除小面積碎點（小物件）
- 值越大，越多細小雜點會被刪除
- 建議起點：`2`

### 線條細化（去除粗邊）

- 用途：讓線條不要過厚、降低粗邊造成的偏移
- 強度太高可能導致細線斷裂
- 建議先從 `1` 開始

### 去除沾黏（智慧修邊）

- 用途：清除相鄰線條黏在一起的小區塊
- 強度太高可能削弱細節
- 建議搭配預覽逐步增加

### 連接鄰近線條（平滑化）

- 用途：修補小縫隙、讓輪廓更連續
- 強度太高可能把不該連接的線條黏在一起

## 實作概要（開發者）

- GUI：`tkinter`
- 影像處理：`Pillow`, `numpy`
- 形態學與骨架化：`scikit-image`
- 路徑簡化：`rdp`（Ramer-Douglas-Peucker）
- DXF 輸出：`ezdxf`
- 外框追蹤：`Potrace`（透過 subprocess 呼叫）

中心線模式大致流程：

1. 圖片前處理
2. 二值化（全域 + ROI 局部閾值）
3. 形態學清理（細化 / 修邊 / 平滑化）
4. 骨架化（skeletonize）
5. 分支修剪（pruning）
6. 路徑抽取
7. 輸出 SVG / DXF

## 常見問題

### 為什麼預覽看起來正常，但輸出不如預期？

請確認：

- 是否選錯模式（外框 / 中心線）
- `雜點移除` 是否太大
- 三個形態學功能是否同時開太強
- ROI 區域閾值是否影響到局部線條

建議作法：

- 一次只開一個功能，強度從 `1` 開始試
- 先調好閾值，再微調形態學功能

### DXF 打開後座標方向看起來不同？

程式在輸出 DXF 時會做座標轉換（包含 Y 軸方向處理），讓 CAD 中的顯示方向更合理。

# 圖片轉 SVG 工具 (Image to SVG Converter)

這是一個簡單易用的 Python 工具，專門將點陣圖（JPG, PNG, BMP 等）轉換為 SVG 向量圖。
本工具特別針對工程用途進行優化，支援「中心線提取」功能，可產出適合 CAD 或雷射切割使用的單線條向量檔。

## 功能特色

*   **圖形化介面 (GUI)**：直觀的操作介面，支援滑鼠滾輪縮放預覽。
*   **雙模式轉換**：
    1.  **中心線提取 (Centerline)**：
        *   使用 Python 內建演算法 (基於 `scikit-image`)。
        *   **CAD 友善**：產出單線條向量，而非雙線輪廓。
        *   **智慧優化**：自動增強對比、銳化影像、修補微小斷裂，並透過骨架修剪演算法去除毛邊與雜訊。
    2.  **輪廓描摹 (Outline)**：
        *   整合 **Potrace** 引擎。
        *   適合圖標、文字或插畫的向量化（產出填色區域）。
*   **自動化依賴管理**：
    *   自動檢查並安裝所需的 Python 套件 (`Pillow`, `scikit-image`, `numpy`, `rdp`)。
    *   自動偵測並下載 `potrace.exe` (若缺失)。

## 系統需求

*   Windows / macOS / Linux
*   Python 3.6 或更高版本

## 安裝與執行

1.  確保電腦已安裝 Python。
2.  下載本專案程式碼。
3.  執行主程式：
    ```bash
    python ConvertTool.py
    ```
4.  **首次執行**：程式會自動檢查環境，若缺少必要套件或 Potrace，會彈出視窗詢問並自動安裝/下載。

## 使用說明

1.  **開啟圖片**：點擊左上角的「開啟圖片」按鈕，選擇檔案。
2.  **預覽**：
    *   左側顯示原始圖片。
    *   右側顯示二值化後的預覽（程式已內建最佳化參數）。
3.  **選擇模式**：
    *   **勾選「提取中心單線」**：輸出單條路徑（適合工程圖）。
    *   **取消勾選**：輸出輪廓路徑（適合一般圖形）。
4.  **轉換**：點擊底部的「開始轉換 SVG」按鈕，選擇存檔位置即可。

## 技術細節

*   **前處理**：影像會經過對比度增強 (1.5x) 與銳化濾鏡處理。
*   **骨架化**：採用 8-鄰域連接 (Connectivity-8) 確保線條連續性。
*   **雜訊過濾**：內建修剪機制，會自動移除長度小於 15 像素的孤立雜點與分岔毛邊。
*   **向量簡化**：使用 RDP (Ramer-Douglas-Peucker) 演算法將像素點轉換為平滑的向量線段。
